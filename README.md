# Office Assistant Job Services (simple static version)

Plain HTML, CSS and JavaScript. No install needed.

## Run locally
Open `index.html` in your browser.

## Put it on GitHub Pages
1. Create a new repository on GitHub and upload `index.html`, `style.css`, `script.js`, `README.md`.
2. Go to Settings > Pages. Under Source choose "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
3. After a minute your site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Edit jobs
Jobs are in the `JOBS` array at the top of `script.js`. All current jobs are DEMO samples.

## Limits
GitHub Pages is static, so there is no login, database or CV upload. Saved jobs are stored in the visitor's browser. Forms open WhatsApp with the message filled in. For real accounts and dashboards, use the Next.js + Supabase version.
